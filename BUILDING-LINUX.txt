Dylan's Optimized SRB2 Build V1.6.0 for Linux

Install a C compiler, make, pkg-config, and development packages for SDL2,
SDL2_mixer, libpng, zlib, curl, and miniupnpc. Run sh ./build-native-linux.sh.
The executable is built in bin-linux-v160-native. To include GME and OpenMPT
decoders, install their development packages and run the script with
--full-music. Supply the official SRB2 2.2.15 game data separately.

The distributed x86_64 executable targets glibc 2.17 and uses SDL2 2.0.18 or
newer and the OpenSSL build of libcurl.so.4 from the host system. The release
bundles SDL2_mixer. Host libraries can require a newer glibc.
